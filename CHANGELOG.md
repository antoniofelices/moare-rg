# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0 — Initial release

- Registered `project`, `publication`, and `researcher` custom post types.
- Registered `year` hierarchical taxonomy attached to `publication`.
- ACF Pro field groups for all three CPTs (placeholder fields, ready to be replaced).
- Admin notice when ACF Pro is not active.
- FSE block templates for archive and single views of all three CPTs.
- Dynamic block `moare-rg/publications-by-year` listing publications grouped by year term.
